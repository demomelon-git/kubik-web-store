Кубик скоро

Предварительная версия

Кубик расширения — дом для внутренних расширений в формате .kubik. Они ставятся прямо в него, общаются друг с другом, а главный поиск запускается по ID этого расширения. Кубик пока только выходит: сейчас доступна предварительная версия, а первые внутренние расширения — «Кубик Веб-поиск» и «Кубик для GitHub» — уже лежат в магазине.

Смотреть в магазине

Как это связано

Простые версии для Chrome и Firefox работают сами по себе и обновляются через магазин. Версия «Кубик» запускает то же самое как внутреннее расширение: Chrome и Firefox ведут себя почти одинаково, различается только упаковка. Подробнее о каждом продукте: Кубик Веб-поиск, Кубик Стиль и Кубик расширения.
