# Формат .kubik

`.kubik` — обычный zip-архив (без папки внутри), который устанавливается в «Кубик расширения». В корне обязателен файл `kubik.json`.

## kubik.json
```json
{
  "id": "kubikweb",            // a–z и 0–9, 3–24 символа; он же префикс имени файла
  "name": "Кубик Веб-поиск",
  "version": "1.0.0",
  "author": "demomelon-git",
  "description": "…",
  "entries": { "newtab": "newtab.html", "search": "results.html", "main": "index.html" },
  "service": { "scripts": ["engines.js", "service.js"] },   // необязательно: скрипты, которые работают в фоне, пока открыт Кубик
  "permissions": {
    "hosts": ["api.github.com", "*.bing.com"],              // сайты, к которым можно обращаться через KX.fetch (https)
    "capabilities": ["google", "install"]                   // google — поиск Google; install — установка других .kubik
  },
  "provides": ["search"],
  "requires": { "host": "0.1.0" }                           // минимальная версия «Кубик расширения»
}
```
Файл называется `<id>-<версия>.kubik`, например `kubikweb-1.0.0.kubik`.

## Страницы
- `entries.newtab` — главная страница (открывается в новой вкладке, если выбрана в настройках).
- `entries.search` — страница результатов, ей передаётся `KX.params.q`. Главный поиск запускается по ID «Кубик расширения»: `…/app.html?q=%s` или `https://127.0.0.1/?q=%s`.
- `entries.main` — страница по кнопке «Открыть» в менеджере.

Страницы работают в изолированном окне. Правила: скрипты подключай как `<script src="…">` и пиши так, чтобы они выполнялись после загрузки DOM (событие DOMContentLoaded не придёт); не используй `onclick="…"` в разметке, вешай обработчики через `addEventListener`; ничего не подключай с чужих сайтов (внешние скрипты не загрузятся), клади всё в пакет. Все скрипты страницы выполняются как один общий скрипт в порядке подключения.

## API: объект KX
| Вызов | Что делает |
|---|---|
| `KX.params` | параметры страницы (например `{q: "..."}`) |
| `KX.fetch(url, {method, headers, body})` | запрос https к сайту из `permissions.hosts`; ответ с `ok`, `status`, `text()`, `json()` |
| `KX.google(q, start)` | результаты Google (нужна возможность `google`) |
| `KX.send(id, data)` | сообщение другому внутреннему расширению; вернёт его ответ |
| `KX.onMessage((data, {from}) => ответ)` | принять сообщение; можно вернуть значение или промис |
| `KX.storage.get(k)` / `KX.storage.set(k, v)` | своё хранилище |
| `KX.list()` | установленные внутренние расширения |
| `KX.open(id, страница, params)` | открыть страницу (`newtab`, `search`, `main` или путь к html) |
| `KX.openUrl(url, {newTab})` | открыть обычный сайт; ссылки `<a href="https://…">` открываются сами |
| `KX.install(url)` | установить `.kubik` по ссылке (нужна возможность `install`) |
| `KX.setTitle(t)` | заголовок вкладки |

Служба (`service`) нужна, чтобы расширение отвечало на `KX.send`, пока его страница не открыта. Службы работают, только пока открыта вкладка «Кубик расширения».
