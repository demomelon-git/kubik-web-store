Кубикспециальная версия для браузера Kopi

Скачать расширение .kd

Главная страница с поиском, быстрыми ссылками и внутренним адресом kubik://new_tab.

Возможности

  • Регистрация сайта kubik://new_tab через kopi.register_site().
  • Автоматическое назначение новой главной страницы через kopi.set_new_tab().
  • Поиск через Google, Bing, Brave, DuckDuckGo и Startpage.
  • Быстрый доступ к https://127.0.0.1/ и Kubik Web Store.
  • Только HTML и JavaScript — без Chrome/Firefox manifest и API.

Запрашиваемые разрешения

Расширение запрашивает доступ только к доменам, для которых есть ссылки на главной странице:

  • www.google.com
  • www.bing.com
  • search.brave.com
  • duckduckgo.com
  • www.startpage.com
  • 127.0.0.1
  • demomelon-git.github.io

Идентификаторы Data Kopi не читаются и не отправляются: поисковой главной странице они не нужны.
