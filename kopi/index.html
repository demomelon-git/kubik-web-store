Кубикспециальная версия для браузера Kopi

Скачать расширение .KD

Главная страница и поиск с внутренним адресом kubik://new_tab.

Возможности

  • Собственная страница новой вкладки.
  • Регистрация kubik://new_tab через API Kopi.
  • Поиск Google, Bing, Brave, DuckDuckGo и Startpage.

Разрешения

Сайты объявлены в kd.json для подтверждения штатным диалогом Kopi. Расширение не вызывает отсутствующий в просмотренной реализации метод request_permission() и не запрашивает личные данные Data Kopi.
